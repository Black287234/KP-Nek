# Учёт выдачи оборудования сотрудникам

Курсовой проект по МДК.01.01 «Разработка программных модулей».
Тема 15: «Проектирование и разработка модуля учета выдачи оборудования сотрудникам».
Выполнил: Пономарев Никита Сергеевич, группа ИСиП-23/1.

## Этап 1

- Решение `IssueDesk.sln`, веб-приложение `IssueDesk` на Blazor (интерактивные компоненты на сервере), .NET 10.
- Класс «Оборудование» (`Domain/Equipment.cs`): инвентарный номер, наименование, вид, серийный номер, состояние.
- Пять единиц оборудования хранятся в памяти; страницы «Перечень оборудования» и карточка оборудования.
- Несуществующий адрес — страница «Страница не найдена»; несуществующий код оборудования — сообщение «Запись не найдена».

## Запуск

```
dotnet run --project IssueDesk
```

Адрес: http://localhost:5097
