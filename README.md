# EquipmentIssue — модуль учёта выдачи оборудования сотрудникам

Курсовая работа, тема №15: «Проектирование и разработка модуля учета выдачи оборудования сотрудникам».
ЧПОУ «Сургутский колледж предпринимательства», 2026. МДК.01.01 «Разработка программных модулей».

**Состояние: этап 2 — постоянное хранилище данных и первая рабочая версия.**

## Что нужно установить
| Программа | Версия | Проверка |
|---|---|---|
| .NET SDK | 10.0 | `dotnet --version` → `10.x.x` |
| Git | любая | `git --version` |
| Браузер | любой | — |

Интернет нужен при первой сборке (пакеты NuGet) и для оформления страниц (Bootstrap с CDN).

## Запуск (PowerShell)
```powershell
dotnet run --project EquipmentIssue
```
Открыть http://localhost:5070. Остановить — `Ctrl+C`. В Visual Studio: открыть `EquipmentIssue.sln`, F5.

## База данных и учебные данные
- SQLite через Entity Framework Core 10.0.15 (отдельно ставить SQLite не нужно).
- При запуске `Database.Migrate()` создаёт файл `EquipmentIssue/equipment.db` и таблицы
  `Equipment`, `Employees`, `Operations` по миграции `Migrations/InitialCreate`.
- `Data/DbSeeder.cs` при пустой базе добавляет учебные данные: 12 единиц оборудования, 8 сотрудников.
- **Восстановление учебной базы:** остановить приложение, удалить `EquipmentIssue/equipment.db`, запустить снова.
- Другой способ: `dotnet tool install --global dotnet-ef`, затем `dotnet ef database update --project EquipmentIssue`.

Пакеты NuGet (в `EquipmentIssue.csproj`): `Microsoft.EntityFrameworkCore.Sqlite 10.0.15`, `Microsoft.EntityFrameworkCore.Design 10.0.15`.

## Полный проход
1. «Оборудование» → «+ Добавить оборудование»: OB-0601, «Планшет Huawei MatePad 11», категория «Планшеты» → «Сохранить».
2. В карточке «Изменить» → серийный номер HW-77 → «Сохранить».
3. Остановить приложение (`Ctrl+C`), запустить снова → OB-0601 на месте с серийным номером.

Проверки ввода: пустое наименование → «Укажите наименование»; повтор OB-0001 →
«Оборудование с инвентарным номером OB-0001 уже есть в справочнике»; сотрудник без ФИО → «Укажите ФИО»;
`/Equipment/Details/999` → «Запись не найдена (404)».

Удаления нет: сотрудник отмечается уволенным (кнопка «Отметить увольнение»), оборудование будет списываться
на этапе 3 — история операций должна сохраняться.
