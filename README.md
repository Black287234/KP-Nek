## Запуск (PowerShell)
```powershell
dotnet run --project EquipmentIssue
```
Открыть http://localhost:5070. Остановить — `Ctrl+C`. В Visual Studio: открыть `EquipmentIssue.sln`, F5.

## База данных и учебные данные
- SQLite через Entity Framework Core 10.0.15 (отдельно ставить SQLite не нужно).
- При запуске `Database.Migrate()` создаёт файл `EquipmentIssue/equipment.db` и таблицы
  `Equipment`, `Employees`, `Operations` по миграции `Migrations/InitialCreate`.
- `Data/DbSeeder.cs` при пустой базе добавляет учебные данные: 12 единиц оборудования, 8 сотрудников, 18 операций
  (даты операций отсчитываются от дня первого запуска).
- **Восстановление учебной базы:** остановить приложение, удалить `EquipmentIssue/equipment.db`, запустить снова.
- Другой способ: `dotnet tool install --global dotnet-ef`, затем `dotnet ef database update --project EquipmentIssue`.

Пакеты NuGet (в `EquipmentIssue.csproj`): `Microsoft.EntityFrameworkCore.Sqlite 10.0.15`, `Microsoft.EntityFrameworkCore.Design 10.0.15`.

## Главное правило
Выдать можно только оборудование, которое **находится на складе** (последняя операция по нему — не выдача),
**не списано** и **не требует ремонта**, и только **работающему** сотруднику. Дата операции не может быть
в будущем и раньше последней операции по этому оборудованию. Признак «у кого сейчас» не хранится,
а вычисляется по истории операций (`Services/OnHandCalculator.cs`).

## Сценарии демонстрации
**Успех.** «Выдача» → OB-0003 «Ноутбук ASUS ExpertBook B1», сотрудник Попова М. В., сегодняшняя дата →
«Оформить выдачу» → карточка: «у Попова Мария Викторовна, выдано …», в истории — операция «Выдача».

**Отказ.** API или подмена формы: выдать OB-0001 (уже у Кузнецова А. И.) другому сотруднику →
«Оборудование «Ноутбук Lenovo ThinkPad E15» уже выдано: находится у Кузнецов А. И. с …. Сначала оформите возврат».
Выдача OB-0301 (требует ремонта) → отказ; выдача уволенной Фёдоровой Е. П. → отказ.

**Возврат.** «Возврат» → OB-0002 (у Смирновой О. А.) → состояние «Требует ремонта» без комментария → отказ
«Опишите неисправность…»; с комментарием → возвращено, выдача заблокирована до ремонта.

## Адреса
| Адрес | Что показывает |
|---|---|
| `/Equipment` | справочник: поиск, фильтры по категории, состоянию, местонахождению |
| `/Equipment/Details/1` | карточка: где находится, изменение состояния, списание, история |
| `/Employees`, `/Employees/Details/3` | сотрудники, оборудование на руках, история, увольнение |
| `/Operations/Issue` | выдача |
| `/Operations/Return` | возврат с указанием состояния |
| `/Operations/OnHand` | оборудование у сотрудников (фильтр по сотруднику, подразделению) |
| `/Operations` | история операций (оборудование, сотрудник, вид, период) |
| `/api/equipment`, `/api/employees`, `/api/onhand`, `/api/operations` | JSON |
| `POST /api/operations/issue`, `POST /api/operations/return` | выдача и возврат через API |
