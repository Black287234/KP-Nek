# Учёт выдачи оборудования сотрудникам

Курсовой проект по ПМ.01, МДК.01.01 «Разработка программных модулей».
Тема 15: «Проектирование и разработка модуля учета выдачи оборудования сотрудникам».
Выполнил: Пономарев Никита Сергеевич, группа ИСиП-23/1. Руководитель: Крючков Виталий Владимирович.

## Состав

| Каталог | Содержимое |
|---|---|
| `IssueDesk/Domain` | классы предметной области: оборудование, сотрудник, закрепление (выдача — возврат) |
| `IssueDesk/Features` | функции, сгруппированные по смыслу: страницы Blazor, обработчики действий и настройки таблиц рядом |
| `IssueDesk/Data` | контекст EF Core, миграции, учебные данные |
| `IssueDesk/Shared` | общие компоненты и тип результата `Result` |
| `IssueDesk.Tests` | 40 тестов xUnit для обработчиков с базой SQLite в памяти |
| `tests/e2e` | сценарии работы пользователя в браузере (pytest, Playwright) |

## Запуск

Требуется .NET SDK 10.

```
dotnet run --project IssueDesk
```

Адрес: http://localhost:5097. База `IssueDesk/issuedesk.db` создаётся по миграциям при первом запуске и заполняется
учебными данными; чтобы вернуть учебные данные, удалите файл базы. Тесты: `dotnet test`.

## Этап 4

- 40 тестов xUnit: выдача, возврат, сроки, состояние, пересечение периодов, уникальный индекс, справочники, история.
- 24 сценария в браузере (`tests/e2e`), результаты и снимки экрана — `docs/evidence`.
- Дефекты, найденные при проверке кода этапа 3, и их исправление — `docs/defects.json`.

## Этап 3

- Закрепление оборудования за сотрудником (`Domain/Assignment.cs`): одна запись на цикл «выдача — возврат»; миграция `AddAssignments`.
- Выдача: только исправное, не списанное и не выданное оборудование; только работающему сотруднику; дата — не позже
  сегодняшней и не ранее 30 дней; плановая дата возврата — не раньше даты выдачи, срок не более 365 дней.
- Частичный уникальный индекс `UX_Assignments_OpenPerEquipment` не допускает двух незакрытых выдач одной единицы.
- Возврат: дата не раньше даты выдачи, состояние при возврате обновляет состояние оборудования; при неисправности обязательно описание.
- Оборудование у сотрудников (группировка по сотрудникам, просроченный срок возврата), история операций с отбором,
  карточки оборудования и сотрудника с историей.
- Нельзя списать выданное оборудование и отметить увольнение сотрудника, за которым числится оборудование.

## Этап 2

- Хранение в SQLite через Entity Framework Core; миграция `CreateCatalogs` применяется при запуске, пустая база заполняется учебными данными.
- Организация кода по функциям (вертикальные срезы): папки `Features/Equipment`, `Features/Employees` содержат страницы,
  обработчики действий и настройки таблиц (`IEntityTypeConfiguration`).
- Обработчики возвращают результат `Result` (успех или отказ с текстом), а не выбрасывают исключения.
- Оборудование: перечень с поиском и отбором, добавление, изменение, списание с причиной.
- Сотрудники: справочник с поиском и отбором по подразделению, добавление, изменение, отметка увольнения.

## Этап 1

- Решение `IssueDesk.sln`, веб-приложение `IssueDesk` на Blazor (интерактивные компоненты на сервере), .NET 10.
- Класс «Оборудование» (`Domain/Equipment.cs`): инвентарный номер, наименование, вид, серийный номер, состояние.
- Пять единиц оборудования хранятся в памяти; страницы «Перечень оборудования» и карточка оборудования.
- Несуществующий адрес — страница «Страница не найдена»; несуществующий код оборудования — сообщение «Запись не найдена».
