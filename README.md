# EquipmentIssue — модуль учёта выдачи оборудования сотрудникам

Курсовая работа, тема №15: «Проектирование и разработка модуля учета выдачи оборудования сотрудникам».
ЧПОУ «Сургутский колледж предпринимательства», 2026. МДК.01.01 «Разработка программных модулей».

**Состояние: этап 1 — планирование и первый запуск.**

## Что нужно установить
| Программа | Версия | Проверка |
|---|---|---|
| .NET SDK | 10.0 | `dotnet --version` → `10.x.x` |
| Git | любая | `git --version` |
| Браузер | любой | — |

Интернет нужен для оформления страниц (Bootstrap подключается с CDN).

## Запуск (PowerShell)
```powershell
dotnet run --project EquipmentIssue
```
Открыть http://localhost:5070. Остановить — `Ctrl+C`. В Visual Studio: открыть `EquipmentIssue.sln`, F5.

## Что проверить
| Адрес | Ожидаемый результат |
|---|---|
| `/Equipment` | 8 учебных единиц оборудования |
| `/Equipment/Details/1` | карточка «Ноутбук Lenovo ThinkPad E15» |
| `/Equipment/Details/999` | страница «Запись не найдена (404)» |
| `/api/equipment` | JSON-массив оборудования |
| `/api/equipment/999` | `{"error":"Оборудование с Id = 999 не найдено"}`, код 404 |

## Хранение данных
Учебные данные пока хранятся в памяти (`Data/EquipmentStore.cs`) и сбрасываются при перезапуске.
На этапе 2 хранение переводится на SQLite + Entity Framework Core.
